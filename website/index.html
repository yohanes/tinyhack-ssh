Tinyhack SSH

A terminal emulator for Android powered by the Ghostty VT core, with GNU Bash, BusyBox, OpenSSH, and rsync bundled — plus an embedded SSH agent that supports FIDO2 security keys.

Tinyhack SSH is an independent, unofficial Android port. It uses the open-source Ghostty VT library and is not affiliated with or endorsed by the Ghostty project.

Release status Privacy policy

Features

Ghostty VT Core

Accurate VT100/XTerm emulation, true color, pixel-aligned monospace rendering, and optional per-profile Kitty graphics.

Bundled Userland

GNU Bash 5.2, BusyBox (270+ utilities), OpenSSH 10.5, and rsync 3.5 — no root required.

SSH Agent + Security Keys

Embedded ssh-agent with Ed25519/RSA support and FIDO2 -sk keys backed by the Android Keystore and biometrics.

Multi-Session & Profiles

Run many sessions at once; save LOCAL/SSH connection profiles and connect with one tap.

Termux-like UX

Extra-keys toolbar, three-finger menus, scrollback and selection; sessions keep running in the background when you close the app.

rsync & Secure Transfers

Bundled rsync, scp, and sftp transfer files to destinations you choose. The Play build omits broad storage access; the F-Droid/direct build offers a separate, user-enabled Storage Access option.

Secure Defaults

SSH agent forwarding, Kitty graphics, and OSC 52 clipboard writes are disabled unless you enable them for a profile. Terminal links require confirmation by default.
