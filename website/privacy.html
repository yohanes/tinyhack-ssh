Privacy Policy

Last updated: August 28, 2026

Short version: Tinyhack SSH does not collect any data.

No data collection

Tinyhack SSH and its developer do not collect, receive, sell, or share personal information or device data. The app contains no analytics, advertising, crash-reporting, or tracking SDKs. Network connections occur only when you direct a terminal tool such as ssh, mosh, rsync, or wget to contact a destination you choose. Data sent in those connections goes directly to that destination, not to Tinyhack SSH or its developer.

Data stored on your device

  • Shell history and files you create or download are stored locally in the app's private storage on your device. Live terminal sessions exist only on your device while they are running.
  • SSH keys you create or import are stored in the app's private storage (and/or the Android Keystore for security keys) and never leave your device unless you use them to connect to a server of your choice.
  • Preferences (fonts, toggles such as Storage Access) are stored locally.

Retention and deletion

Tinyhack SSH has no developer-operated server and therefore has no server-side user data to retain or delete. Local app data remains on your device until you delete it, remove individual profiles, keys, history, or files, clear Tinyhack SSH's app data in Android settings, or uninstall Tinyhack SSH. Uninstalling or clearing app data removes Tinyhack SSH's private local data.

Security

Android isolates Tinyhack SSH's private files from other apps. Saved connection-profile passwords are encrypted using a key held by Android Keystore. Android-backed security keys are non-exportable. Ordinary imported or generated SSH private-key files remain in the app's private storage and can optionally be protected with an SSH passphrase.

Permissions

  • All files access — optional, off by default. Requested only if you enable "Storage Access", so the bundled shell and rsync can read/write your phone storage.
  • Biometrics — optional, used only to authorize SSH agent operations with security keys.
  • Notifications — optional, used for the visible foreground-service notification that helps terminal sessions remain connected in the background, and for notifications explicitly emitted by terminal programs.

Optional local debug server

The HTTP Debug Server is disabled by default. If you enable it, it listens only on the device loopback interface and requires a randomly generated bearer token stored in Tinyhack SSH's private files. It does not send data to the developer.

Contact
